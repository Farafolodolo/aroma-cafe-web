# Aroma Café Web

Static website for Aroma Café built with vanilla HTML5, CSS3 and JavaScript (no bundlers or frameworks).

## Structure
```
index.html
pages/   menu.html, login.html, contact.html
css/     styles.css, login.css
js/      main.js, login.js
assets/images/
```

## Branches
- `main` – stable production
- `develop` – integration
- `feature/menu-page`, `feature/login-form`, `feature/contact-page` – features
- `hotfix/footer-phone` – urgent footer phone fix

See [CONTRIBUTING.md](CONTRIBUTING.md) for conventions.

## Run
Open `index.html` in a browser, or serve the folder with `python -m http.server`.
